# PRD: Local LPTHW + Focus Tracks Learner

Personal local-only Python learning site. LPTHW skeleton for fundamentals; priority tracks for Async/LLM enterprise patterns and PyTorch.

## Goals

- React UI + FastAPI backend running real local Python
- Code edit, run, interactive stdin, workspace file ops
- Three tracks: lpthw, async-llm (priority), pytorch (priority)
- No public deploy; no verbatim book text in repo

## Non-goals

- Cloud sync, auth, auto-grading OJ, large GPU training platform
